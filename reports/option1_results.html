Shared EEG–MRI embedding from unpaired cohorts: results

22 October 2026 · code train_option1.py (job script train_option1.qsub) · outputs results/option1/

Bottom line. Training EEG together with unpaired ADNI MRI raised EEG AUC over an EEG-only network (0.691 → 0.725), but the ablations show the gain is not MRI information: shuffling the MRI labels keeps most of it, and replacing MRI with age/sex alone does slightly better than MRI (-0.012). The joint model only matches plain EEG logistic regression (-0.002). The contrastive loss acts as a regularizer for a small network; we find no evidence that unpaired MRI improves EEG prediction (or vice versa).

2. Method

Model

  • Encoders: one MLP per modality (EEG 26→32→16; MRI 321→64→16; ReLU, dropout 0.3) into a shared 16-d embedding.
  • Shared head: one linear AD/CN classifier used by both modalities, so “AD” means the same direction in the embedding.
  • Cross-modal supervised contrastive loss (τ = 0.1): each EEG embedding is pulled towards MRI embeddings with the same label and away from the other label, and vice versa. No subject pairing is used — only labels.
  • Loss = BCEtarget + 1.0·BCEauxiliary + 0.5·contrastive; BCE class-weighted for imbalance.
  • Full-batch Adam, lr 0.001, weight decay 0.001, 300 epochs. All hyperparameters fixed before running; nothing was tuned on test folds.
  • At test time a subject is predicted from its own modality only.

Evaluation

  • EEG CV: 5-fold × 10 repeats over all EEG subjects, stratified by dataset × diagnosis; all MRI subjects are auxiliary training data.
  • EEG transfer: train on one EEG dataset (+ MRI), test on the other; 10 seeds.
  • MRI CV: 5-fold × 3 repeats over ADNI; all EEG subjects auxiliary.
  • Imputation and z-scoring fitted on training rows only (EEG per dataset; the unseen transfer dataset is z-scored with its own, label-free statistics).
  • Metric: AUC of out-of-fold predictions per repeat; every model uses the same splits, so differences are paired.
  • Comparisons: logistic regression and the same network without the other modality; ablations without the contrastive loss, with auxiliary labels shuffled, and with auxiliary nodes that carry only age + sex.

4. Interpretation

  • EEG separates AD from CN with AUC ≈ 0.73 overall (≈0.80 within ds004504, ≈0.65 within BrainLat) and transfers across datasets at 0.73–0.79.
  • MRI regional features reach AUC ≈ 0.91; adding EEG as auxiliary data changes nothing (+0.001).
  • The joint model's gain over the EEG-only network (+0.034) disappears against the ablations: the shared head alone adds 0.000, the shuffled-label ablation keeps most of the gain, and age/sex-only auxiliary nodes do better than MRI. The contrastive term regularizes the small EEG network, which otherwise overfits; logistic regression gets the same benefit for free.
  • This is the controlled negative result anticipated in the proposal: with unpaired cohorts, the label-aligned shared embedding does not transfer disease information between modalities beyond regularization.

5. Limitations and next steps

  • Hyperparameters were fixed, not tuned (nested CV would tune them without test leakage); the EEG-only network had no early stopping, so logistic regression is the fairer baseline.
  • 132 EEG subjects: AUC differences of ≈0.01 are within noise (SD across repeats 0.01–0.03).
  • BrainLat confounds (recording type matches diagnosis, AD older and less educated) limit what the BrainLat numbers mean.
  • Next: nested-CV tuning, EEG connectivity features, global-only EEG features for cross-dataset robustness, feature importance; and paired EEG–MRI fusion once BrainLat MRI download access is granted.
